De processor (CPU)

De Central Processing Unit is het onderdeel dat instructies uitvoert. De besturingseenheid van de computer.

Wat doet een CPU?

De CPU (Central Processing Unit) voert de instructies uit die bepalen wat een programma precies doet.

Wanneer je bijvoorbeeld een game opstart, verwerkt de processor instructies. Denk aan berekeningen,bewerkingen en het verwerken van gegevens.

Cores en threads

Een core is een fysieke verwerkingseenheid in de processor. Met meerdere cores kan de CPU ook meerdere taken tegelijkertijd uitvoeren.

Een thread is een reeks instructies die door een processorcore kan worden uitgevoerd. Sommige cores ondersteunen meerdere threads.

Van instructies naar machinecode

Een CPU voert instructies uit. Die zijn weergegeven als bytes: sets van acht bits. Een opcode geeft aan welke bewerking uitgevoerd moet worden; andere delen kunnen registers of waarden aanduiden.

WIST JE DAT?

De kloksnelheid geeft aan hoeveel klokcycli een processor per seconde uitvoert. Meer GHz betekent niet automatisch dat een CPU altijd sneller is.
